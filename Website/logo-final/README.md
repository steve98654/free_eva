# Final logo: 中 / US yin-yang with the north star

One-color (Princeton orange #E77500) yin-yang inside the 13-star ring of the 1777 flag.
- 中 sits in the dark half (China), US in the orange half (United States).
- The top star is larger: the north star guiding the relationship.
- Lockup text: MUTUAL RESPECT / 中美相互尊重 / STEP ONE: FREE EVA (stacked) or FREE EVA / MUTUAL RESPECT / 中美相互尊重 (horizontal).

All SVG text is converted to outlines, so no fonts are needed to display them.
